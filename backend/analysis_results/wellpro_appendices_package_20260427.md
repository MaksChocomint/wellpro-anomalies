# Пакет приложений к ВКР

## Тема

**«Разработка информационной системы детекции и анализа аномальных показаний сенсорных датчиков буровых установок»**

### Назначение документа

Настоящий документ подготовлен как пакет приложений к выпускной квалификационной работе. Он фиксирует состав сопроводительных материалов, структуру проекта, используемые данные и список документов, которые могут быть приложены к основной пояснительной записке.

## Приложение А. Исходные нормативные и постановочные документы

В состав приложений целесообразно включить следующие исходные документы:

1. «ТЗ 06.08.2025.docx» - исходное техническое задание;
2. «diploma_review_and_updated_tz_20260426.docx» - актуализированное ТЗ по фактически реализованному проекту;
3. «Задание_на_практику_поиск_аномальных_значений.docx» - задание на практику;
4. «Бакалавр МУ 2026(1).docx» - методические указания;
5. при наличии - акт, письмо о практической значимости или иной внешний подтверждающий документ.

## Приложение Б. Структура проекта

Ниже приведена укрупненная структура репозитория проекта.

### Корневой уровень

- «backend»
- «frontend»
- «docker-compose.yml»
- «seed.sql»
- материалы ВКР и исходные документы

### Структура backend

- «backend/app/main.py» - точка входа FastAPI;
- «backend/app/api/rest.py» - REST-маршруты;
- «backend/app/methods.py» - методы «Z-score», «LOF», «FFT», «AMMAD»;
- «backend/app/models» - модели БД;
- «backend/app/utils» - парсинг и служебные утилиты;
- «backend/app/config/ammad_context.json» - настройки контекста «AMMAD»;
- «backend/app/data/rig_files» - исторические файлы буровой телеметрии;
- «backend/app/data/validation_cases» - тестовые файлы с контролируемыми аномалиями;
- «backend/app/services» - вспомогательные исследовательские скрипты.

### Структура frontend

- «frontend/app/page.tsx» - главный экран;
- «frontend/components/SelectionScreen.tsx» - выбор буровой;
- «frontend/components/AnalysisMethodSelector.tsx» - выбор метода и параметров;
- «frontend/components/GraphGrid.tsx» - графики;
- «frontend/components/StatusDisplay.tsx» - статус нормальной работы и тревоги;
- «frontend/components/AnomalyModal.tsx» - окно списка аномалий;
- «frontend/components/LocalSummaryModal.tsx» - итоговая сводка по локальному анализу;
- «frontend/hooks/useWebSocket.ts» - потоковый режим;
- «frontend/utils/api.ts» - REST-запросы.

## Приложение В. Источники входных данных

### Исторические буровые файлы

Основной исследовательский массив расположен в:

- «backend/app/data/rig_files»

Каталоги именуются по шаблону:

- «cluster_<номер_куста>_well_<номер_скважины>»

Внутри находятся реальные TXT-файлы рейсов буровой телеметрии.

### Валидационные тестовые кейсы

Для проверки методов были подготовлены следующие файлы:

- «ammad_case_00_normal_ok.TXT»
- «ammad_case_01_physical_limits.TXT»
- «ammad_case_02_statistical_spikes.TXT»
- «ammad_case_03_context_stuck_sensor.TXT»
- «ammad_case_04_fft_oscillations.TXT»
- «ammad_case_05_mixed_all_types.TXT»

Эти файлы предназначены для контролируемой демонстрации нормального режима и основных типов аномалий.
